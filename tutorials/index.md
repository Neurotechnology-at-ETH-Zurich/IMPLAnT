# Tutorials

IMPLAnT follows a four-stage workflow. Each stage has its own in-app "?" button with step-by-step instructions — these pages are the map connecting the stages, not a replacement for them.

1. [Pre-surgical planning](pre-surgical-planning) — register the MRI to the atlas and plan electrode trajectories.
2. [During surgery](during-surgery) — correct the plan using real bregma/lambda measurements on surgery day.
3. [Post-implant localisation](post-implant-localisation) — localise electrodes from MRID tags and assign atlas regions.
4. [Electrophysiology visualisation](ephys-visualisation) — view signal traces alongside anatomical labels.
