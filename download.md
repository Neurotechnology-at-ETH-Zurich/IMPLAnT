# Download

Pre-built standalone executables for **Linux** are available on the [Releases page](https://github.com/Neurotechnology-at-ETH-Zurich/IMPLAnT/releases). No Python installation and no separate ANTs install are required — download the executable and configure `paths_config.json` as described in [Configuration](configuration).

{: .note }
Prefer running from source, or building the standalone app yourself? See [Installation](installation).

## Source code

```bash
git clone --recurse-submodules https://github.com/Neurotechnology-at-ETH-Zurich/IMPLAnT.git
```
